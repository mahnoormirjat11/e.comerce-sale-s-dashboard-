# e.comerce-sale-s-dashboard-

## Overview

This project is a Power BI dashboard created to analyze and visualize ecommerce sales performance. The dashboard provides insights into sales trends, profits, customer behavior, and product performance using interactive visualizations.


## Features

* Monthly profit analysis
* Sales performance tracking
* Interactive slicers and filters
* KPI cards for quick insights
* Product/category comparison charts
* Donut and bar chart visualizations



## Dashboard Components

The dashboard contains the following visual elements:

* Profit by Month (Column Chart)
* Sales Distribution (Donut Charts)
* KPI Summary Cards
* Bar Charts for comparison analysis
* Interactive Slicers


## Tools & Technologies

* **Power BI Desktop**
* Data Visualization Techniques
* Business Intelligence & Analytics


## Purpose of the Project

The purpose of this dashboard is to:

* Monitor ecommerce business performance
* Identify profit trends over time
* Support business decision-making
* Present data in a visual and understandable format



 How to Use

1. Install Power BI Desktop.
2. Open the `.pbix` file.
3. Explore the dashboard using filters and slicers.
4. Analyze sales and profit insights.
